Privacy policy — SALVOR uploader

Last updated: 23 November 2026

SALVOR is a private tool used only by the owner of the SalvorLabs YouTube channel.

What it accesses

  • YouTube Data API (youtube scope): uploading videos and editing their titles, descriptions and visibility on the owner's channel.
  • YouTube Analytics API (yt-analytics.readonly): reading view and retention reports for the owner's own channel.

Storage and sharing

The OAuth token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

SALVOR's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
